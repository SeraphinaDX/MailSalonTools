# MailSalonTools

MailSalonTools is a GPLv3 mailbox conversion utility written in Go.

It converts between common mail storage formats while preserving message content and attachments as faithfully as each target format allows.

Planned first-release formats:

- EML
- Maildir
- mbox
- Microsoft Outlook PST

Command-line arguments are the primary interface. Running MailSalonTools without arguments opens a small gotui-based conversion wizard.
